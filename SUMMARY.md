# Summary of Top-Level Folders

This document provides an overview of the top-level folders in the repository and their purposes. When an agent needs to search for specific files or functionality, it should refer to this summary to determine the appropriate folder.

## `searxng/`
- **Purpose:** Contains the code for the searxng application.
- **When to Search:** When looking for application-specific code or configuration.

## `desktop/`
- **Purpose:** Contains code or assets for the desktop application.
- **When to Search:** When looking for desktop-specific code or resources.

## `backend/`
- **Purpose:** Contains backend server code.
- **When to Search:** When looking for server-side logic or APIs.

## `www/`
- **Purpose:** Contains web-related files or a frontend.
- **When to Search:** When looking for client-side code or static assets.

## `ai/`
- **Purpose:** Contains artificial intelligence components or models.
- **When to Search:** When looking for machine learning models or algorithms.

## `scripts/`
- **Purpose:** Contains utility scripts.
- **When to Search:** When looking for automation scripts or utilities.

## `docker-compose.yml`
- **Purpose:** Used for defining and running multi-container Docker applications.
- **When to Search:** When looking for Docker configuration.

## `Caddyfile`
- **Purpose:** Used for configuring the Caddy web server.
- **When to Search:** When looking for web server configuration.

## `README.md`
- **Purpose:** Provides an overview of the project.
- **When to Search:** When looking for general information about the project.

## `AGENTS.md`
- **Purpose:** Contains documentation or information about agents.
- **When to Search:** When looking for agent-specific information.
